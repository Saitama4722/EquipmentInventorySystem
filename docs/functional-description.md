# Функциональное описание системы

## Назначение системы

Автоматизированная информационная система «Учёт оборудования» предназначена для ведения учёта материально-технического оборудования на предприятии. Система обеспечивает регистрацию единиц оборудования, управление их назначением, проведение инвентаризаций и формирование отчётных сведений.

---

## Состав модулей

Система включает следующие функциональные модули:

### 1. Оборудование
Ведение реестра всех единиц оборудования. Каждая запись содержит наименование, инвентарный номер, серийный номер, статус (в эксплуатации / на хранении / списано / в ремонте), привязку к помещению и ответственному сотруднику, а также произвольные примечания. Поддерживаются операции добавления, редактирования, удаления и поиска по реестру.

### 2. Сотрудники
Справочник ответственных лиц. Хранит ФИО, должность и наименование отдела (подразделения). Сотрудник может быть назначен ответственным за одну или несколько единиц оборудования. Поддерживаются операции добавления, редактирования, удаления и поиска.

### 3. Помещения
Справочник мест размещения оборудования. Хранит номер, наименование и описание помещения. Используется для учёта фактического местонахождения оборудования. Поддерживаются операции добавления, редактирования, удаления и поиска.

### 4. Инвентаризации
Модуль проведения инвентаризационных проверок. Позволяет создать новую инвентаризацию с указанием даты, ответственного сотрудника и примечания, после чего проставить результат проверки (обнаружено / не обнаружено / требует уточнения) для каждой единицы оборудования из реестра. Результаты инвентаризации доступны для просмотра в любой момент.

### 5. История перемещений
Журнал всех перемещений оборудования. Записи создаются автоматически при изменении помещения или ответственного сотрудника (как при редактировании карточки оборудования, так и через специальный диалог «Перемещение»). Журнал доступен только для просмотра и поиска. Это обеспечивает полный аудит движения имущества.

### 6. Отчёты
Модуль сводных данных. Предоставляет четыре вида отчётов:
- **Всё оборудование** — полный реестр с текущим состоянием;
- **По помещениям** — количество оборудования в каждом помещении;
- **По сотрудникам** — количество оборудования, закреплённого за каждым сотрудником;
- **Результаты инвентаризаций** — детальные итоги выбранной инвентаризационной проверки.

Любой отчёт может быть экспортирован в файл формата CSV для последующей обработки.

---

## Основные возможности пользователя

- Регистрировать, изменять и удалять записи об оборудовании, сотрудниках и помещениях.
- Назначать оборудование помещениям и ответственным сотрудникам.
- Фиксировать перемещения оборудования с сохранением полной истории.
- Проводить инвентаризации и просматривать их результаты.
- Получать сводные отчёты по оборудованию с возможностью экспорта.
- Выполнять поиск и фильтрацию записей в каждом разделе.

## Практические задачи, решаемые системой

1. Централизованное хранение сведений об оборудовании организации.
2. Контроль местонахождения и ответственности за каждую единицу имущества.
3. Документирование перемещений оборудования для целей внутреннего аудита.
4. Проведение инвентаризаций с фиксацией результатов проверки.
5. Формирование сводной отчётности для руководства и бухгалтерии.
