# Список скриншотов для курсовой работы

Ниже приведён рекомендуемый перечень скриншотов, которые следует включить в пояснительную записку к курсовой работе.

---

## Главное окно и навигация

1. **Главное окно приложения — стартовый экран**
   Вид главного окна сразу после запуска: боковая панель навигации, статистические карточки с количеством оборудования, сотрудников, помещений и инвентаризаций, раздел «О системе».

---

## Раздел «Оборудование»

2. **Список оборудования**
   Страница «Оборудование» с заполненным реестром: таблица с наименованием, инвентарным и серийным номером, статусом, помещением и ответственным сотрудником. Видны кнопки панели инструментов.

3. **Добавление нового оборудования**
   Диалоговое окно «Добавление оборудования»: заполненные поля наименования, инвентарного номера, статуса, помещения и сотрудника.

4. **Редактирование оборудования**
   Диалоговое окно «Редактирование оборудования» с загруженными данными существующей записи.

5. **Перемещение оборудования**
   Диалоговое окно «Перемещение оборудования»: текущие данные о назначении, выбор нового помещения и сотрудника, поле даты перемещения.

---

## Раздел «Сотрудники»

6. **Список сотрудников**
   Страница «Сотрудники» с таблицей: ФИО, должность, отдел/подразделение. Видна строка поиска.

7. **Добавление / редактирование сотрудника**
   Диалоговое окно «Добавление сотрудника» или «Редактирование сотрудника» с полями ФИО, должность, отдел.

---

## Раздел «Помещения»

8. **Список помещений**
   Страница «Помещения» с таблицей номеров, наименований и описаний. Видна строка поиска.

9. **Добавление / редактирование помещения**
   Диалоговое окно «Добавление помещения» или «Редактирование помещения» с полями номера, наименования и описания.

---

## Раздел «Инвентаризации»

10. **Список инвентаризаций**
    Страница «Инвентаризации» с таблицей проведённых проверок: дата, ответственный, количество позиций, примечание.

11. **Создание новой инвентаризации**
    Диалоговое окно «Новая инвентаризация»: поля заголовка (дата, ответственный, примечание) и таблица оборудования с выбором результата проверки для каждой позиции.

12. **Просмотр результатов инвентаризации**
    Диалоговое окно «Результаты инвентаризации»: заголовок с датой и ответственным, информационная панель с числом позиций, таблица с результатами по каждой единице оборудования.

---

## Раздел «История перемещений»

13. **Журнал перемещений**
    Страница «История перемещений» с полной таблицей: дата, оборудование, откуда/куда (помещение и сотрудник), тип изменения, примечание. Видна строка поиска.

---

## Раздел «Отчёты»

14. **Отчёт — Всё оборудование**
    Страница «Отчёты», активна вкладка «Всё оборудование»: таблица со всеми единицами реестра.

15. **Отчёт — По помещениям**
    Страница «Отчёты», активна вкладка «По помещениям»: таблица с количеством оборудования по каждому помещению.

16. **Отчёт — По сотрудникам**
    Страница «Отчёты», активна вкладка «По сотрудникам»: таблица с количеством оборудования, закреплённого за каждым сотрудником.

17. **Отчёт — Результаты инвентаризаций**
    Страница «Отчёты», активна вкладка «Инвентаризации»: выбрана конкретная инвентаризация, отображена таблица результатов проверки.

---

## Итого

Рекомендуемое минимальное количество скриншотов: **17**

При необходимости сократить объём — приоритет отдаётся скриншотам 1, 2, 3, 5, 6, 8, 10, 11, 12, 13, 14.
